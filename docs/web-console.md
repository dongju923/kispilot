# 웹 콘솔

[← README](../README.md)

```bash
kispilot ui           # http://127.0.0.1:8000
```

같은 PC에서만 접속되도록 127.0.0.1에 열립니다. 실전 앱키가 등록되어 있으면 시세가 실시간으로 갱신됩니다.

## 화면

| 메뉴 | 볼 수 있는 것 |
|---|---|
| 대시보드 | 주요 지수, 투자자별 순매수, 순위 스냅샷, 관심종목, 내 계좌 요약, 시장 뉴스 |
| 시장·업종 | 지수 차트·상세, 업종별 시세, 투자자 매매동향(일별), 예상 체결 지수, 증시 자금, 뉴스·공시 |
| 순위 분석 | 등락률·거래량·체결강도 등 순위 (시장·정렬·가격 조건) |
| 종목 분석 | **시세·호가** — 차트, 기간별 시세, 호가, 체결 · **투자자·수급** — 투자자별 매매동향, 회원사, 프로그램 매매, 공매도·대차 · **재무·기업정보** — 기업 기본정보, 재무제표, 투자 지표 |
| ETF | 차트·NAV, NAV 비교 추이, 구성 종목 |
| 선물/옵션 | KOSPI200 선물·옵션 전광판(주간·야간), 고른 종목의 차트·호가·체결 — [선물 · 옵션](futures-options.md) 참고 |
| 주문 | 호가를 보며 주문 입력(현금·신용·예약), 주문 목록 정정·취소, 체결 내역, 보유·매도 가능 수량 |
| 계좌 | 보유 종목, 자산 구성, 통합 증거금, 기간별 손익 분석 |
| 백테스트 | 기본 전략·커스텀 전략 실행, 설정 여러 개 비교, 여러 종목 포트폴리오, 거래 내역 |

- 상단의 **실전 / 모의** 전환으로 주문·계좌 화면이 쓰는 계좌를 바꿉니다.
- 상단의 **실시간** 칩을 누르면 실시간을 일시정지하고 REST 조회로 바꿉니다 (다시 누르면 재개).
- 키 없이도 백테스트와 종목 차트(yfinance)는 쓸 수 있습니다.

## 실시간 시세

KIS 는 앱키 하나당 실시간 접속을 하나만 허용합니다. 웹 콘솔은 접속 하나를 여러 화면이 나눠 씁니다.

- 한 번에 구독할 수 있는 종목·종류는 최대 41건입니다. 넘치는 구독은 받지 않고, 상단 칩에 "실시간 (일부)" 로 알려 줍니다.
- 같은 앱키로 다른 프로그램이 실시간에 접속해 있으면 연결되지 않습니다 (30초 뒤 다시 시도).

## 다른 기기에서 접속

```bash
kispilot ui --host 0.0.0.0        # 같은 네트워크의 휴대폰·태블릿에서 접속
```

- 이때는 **접속 키**가 자동으로 켜집니다. 서버를 켠 터미널에 나온 주소(`?key=…`)로 처음 한 번 접속하면 그 기기는 기억됩니다.
- 이 화면에는 로그인이 없고 실전 주문까지 되므로, 공용 네트워크에서는 열지 마세요.
- 포트를 바꾸려면 `--port 8080`.
