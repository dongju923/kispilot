# 선물 · 옵션

[← README](../README.md) · [웹 콘솔](web-console.md)

웹 콘솔의 **선물/옵션** 메뉴와 AI 에이전트(MCP)에서 KOSPI200 선물·옵션 시세를 봅니다. 지금은 **시세 조회만** 됩니다 (주문·잔고는 아직 없음).

## 다루는 상품

| 상품 | 주간 | 야간 |
|---|---|---|
| KOSPI200 선물 | ✔ | ✔ |
| 미니 KOSPI200 선물 | ✔ | — (야간에 거래되지 않음) |
| KOSPI200 옵션 | ✔ | ✔ |
| 미니 KOSPI200 옵션 | ✔ | ✔ |
| 위클리 옵션 (목요일 · 월요일 만기) | ✔ | ✔ |

스프레드, 코스닥150, 주식·상품 선물옵션은 다루지 않습니다.

## 주간 · 야간

- 주간장 08:45–15:45, 야간장(KRX) 18:00–다음 날 06:00 입니다 (공휴일은 반영하지 않음).
- 페이지를 열면 지금 시간에 맞는 장이 선택됩니다. 위쪽 **주간 / 야간** 으로 바꿀 수 있습니다.
- 장이 열려 있지 않을 때는 "장 마감 기준 (마지막 거래 값)" 으로 표시됩니다.

## 화면

**전광판**

- **선물** — 월물마다 현재가, 전일대비, 거래량, 미결제약정, 베이시스, 잔존일. 5초마다 갱신합니다.
- **옵션** — 상품(일반·미니·위클리)과 만기를 고르면 행사가를 가운데 두고 콜(왼쪽)·풋(오른쪽)을 보여줍니다.
  등가격(ATM) 행이 강조되고, 칸에 마우스를 올리면 이론가·내재변동성·델타가 보입니다. 30초마다 갱신합니다.

**상세** — 전광판에서 선물 행이나 옵션 칸을 누르면 아래에 그 종목이 열립니다.

- 헤더: 현재가·등락, 시가·고가·저가, 거래량, 미결제·증감, 이론가, 잔존일 (선물은 베이시스, 옵션은 행사가·내재변동성·델타)
- 호가 5단계와 체결이 **실시간**으로 갱신됩니다 (실전 앱키 필요).
- 차트: 1분·5분·30분·일·주·월봉. 실시간 체결이 마지막 봉에 바로 반영됩니다.

## 알아 둘 점

- **옵션 전광판은 ATM 근처 21개 행사가만** 조회합니다. 월물 하나에 행사가가 수백 개라, 기준가(주간은 KOSPI200 지수, 야간은 최근월 선물)에
  가까운 것만 골라 콜·풋 시세를 하나씩 받습니다. 한 번 조회에 약 3초 걸립니다.
- **만기된 월물**은 그날 장이 끝나면 목록에서 빠집니다 (주간은 만기일 당일까지 최종 가격을 보여줌).
- **거래가 드문 옵션**은 호가·체결이 비어 있거나, 차트에 봉이 몇 개뿐일 수 있습니다 (체결 없는 분은 봉을 만들지 않음).
- 실시간은 고른 종목 하나의 체결·호가(2건)만 구독합니다. 전광판 전체는 실시간이 아니라 주기적으로 다시 조회합니다.
- 선물·옵션 과거 시세는 yfinance 에 없어 KIS API 로만 받습니다. 일봉은 최근 약 300개, 분봉은 1분 약 400개 · 5분 약 300개 · 30분 약 200개까지 봅니다.
- AI 에이전트(MCP)에서도 같은 시세를 조회할 수 있습니다: `fo_futures_board`, `fo_option_expiries`, `fo_option_board`, `futureoption_inquire_price` · `futureoption_inquire_asking_price`, `chart_bars(kind="fo")` — [AI 에이전트 (MCP)](mcp.md) 참고.
